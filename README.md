# PATH

**Know Scripture. Walk the path.**

PATH is a Bible learning app designed to help people actually know Scripture—not just read it. It combines guided learning journeys, connected biblical knowledge, retrieval practice, and demonstrated mastery.

## Core learning loop

**Read → Explore → Understand → Remember → Test → Connect → Progress**

## Product principles

- Scripture is the source; explanations and commentary are clearly distinguished from the text.
- Progress reflects understanding and recall, not empty points or pressure-driven streaks.
- People, places, events, themes, and passages connect into a navigable knowledge graph.
- AI supports study with sourced context; it is not presented as biblical authority.
- Bible translation licensing must be confirmed before distributing text.

## First learning journey

**The Life of David** — from David's anointing and Goliath through kingship, the Davidic covenant, the Psalms, and David's place in the larger story of Scripture.

Each step follows: **Read → Explore → Understand → Remember → Test → Connect.**

## Initial build direction

- React Native + Expo + TypeScript for mobile
- Next.js for web
- A shared monorepo for learning logic and data models
- Neon Postgres for structured data
- Vercel for web deployment and AI infrastructure

## Status

Product foundation in progress. The next milestone is a working monorepo scaffold and the first typed PATH journey model.
