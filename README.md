# Path

Path is a Bible-reading app focused on helping people build a steady, thoughtful Scripture-reading habit.

## Initial product direction

- Browse the books of the Bible and navigate chapters.
- Follow a daily reading path and track progress.
- Save bookmarks and personal reflections.
- Keep the interface calm, accessible, and mobile-first.
- Choose a Bible translation only after confirming its licensing and distribution terms.

## Build direction

Start with Expo and React Native so the app can target Android and iOS from one codebase. Keep the first milestone small: app shell, navigation, reading-plan structure, and a clear path for adding licensed Scripture content.

## Status

Early scaffold — implementation and tests are still to come.
